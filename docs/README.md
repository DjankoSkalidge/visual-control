# Visual Control documentation

Visual Control is a Linux app for live visuals. Drop in an image or video, and it plays on a silent loop while the rotary encoders, sliders and pads on a MIDI controller drive effects in real time. A MIDI file, such as a drum loop, or an audio file, such as an mp3 of a song, can trigger effects too.
